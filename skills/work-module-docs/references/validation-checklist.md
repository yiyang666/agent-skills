# 交付检查清单

## README.md

- 存在模块概述、功能、边界、目录结构、架构设计和核心流程。
- 至少包含一张与代码一致的 Mermaid 架构图。
- 跨组件模块包含时序图；纯库模块包含调用流程图。
- 接口、配置、启动、错误处理、日志和限制均有代码或用户说明作为依据。
- 目录树只展示有设计意义的路径。
- 没有模板占位符、伪造命令、真实凭证或未经确认的测试结论。

## TEST_GUIDE.md

- 存在测试范围、环境准备、启停、状态检查、日志和常用命令。
- 至少包含正常路径、边界条件和常见异常三个场景。
- 每个场景包含前置条件、步骤、预期结果、观察点和清理动作。
- 未实际执行的场景标为“待执行”，没有写成“已通过”。
- 不会默认连接生产环境、清理真实数据或控制未授权设备。

## 一致性

- 两份文档中的模块名、进程名、命令、参数、端口、日志路径和配置位置一致。
- Markdown 相对链接有效，代码块闭合，Mermaid 语法可解析。
- 所有 `待确认` 都说明缺少什么证据。
- 交付说明列出分析范围、实际验证和遗留问题。
