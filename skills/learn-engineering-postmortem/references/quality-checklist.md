# 复盘文档质量清单

写完或发布前快速过一遍：

## 正确性

- [ ] 现象与复现条件写清楚
- [ ] 根因可被代码/协议行为证实，不是猜测堆砌
- [ ] 主因与强化因素已分开
- [ ] 每个方案点都能指回至少一条根因

## 表达

- [ ] 开篇有一句话结论或目标行为
- [ ] 有分层（P0/P1/P2 或类似），避免“大而全一次做完”
- [ ] 面试段可独立口述，不依赖上下文
- [ ] 发散项写成可执行检查问题，而非空泛原则

## 发布与安全

- [ ] 无 Token / Secret / 内网敏感地址 / 未授权数据
- [ ] 钉钉目录为「我的文档 / 工程设计复盘」
- [ ] 已 `doc read` 回读标题与开头内容
- [ ] 交付表含链接与一句话结论
