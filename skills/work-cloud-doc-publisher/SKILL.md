# 工作云文档发布

把本地文档可靠地发布到用户指定的飞书或钉钉空间。优先复用平台官方 CLI 自带的 Agent Skills，让官方 Skill 决定当前命令参数，禁止凭记忆猜测可能已经变化的命令。

## 必要输入与默认值

收集并解析：

| 项目 | 规则 |
|---|---|
| 源文档 | 必填；支持一个或多个明确路径 |
| 平台 | 必须是 `飞书`、`钉钉` 或 `都发布`；未指定时只询问这一项 |
| 目标文件夹 | 可选；默认 `<模块名称>设计` |
| 文档标题 | 可选；默认取源文档第一个 H1，缺少 H1 时取不含扩展名的文件名 |
| 模块名称 | 优先取用户指定值，其次从模块目录名或 README 标题推断；仍不唯一时询问 |
| 同名策略 | 默认更新唯一的同名文档；不存在则创建；出现多个同名候选或覆盖风险时询问 |

不得把同一个源文档合并进一个云文档，除非用户明确要求。`README.md` 与 `TEST_GUIDE.md` 默认发布为同一文件夹中的两篇文档。

## 工作流

### 1. 校验本地源文档

1. 解析真实路径，确认文件存在、可读且位于用户授权的工作区。
2. 检查文件不是空文件，提取 H1、相对路径和内容摘要。
3. 检查 Markdown 中的相对图片和链接；云端无法访问的本地资源必须在发布计划中标明。
4. 计算内容哈希，用于发布前后核对和重复执行判断；不要把哈希当作文档业务版本号。

### 2. 定位官方 CLI 与 Skills

读取 [平台路由与发现](references/platform-routing.md)。只检查列出的标准 Skill 目录和可执行文件，不递归搜索整个用户主目录。

- 飞书：优先读取 `lark-shared`、`lark-doc`，涉及目录或权限时再读取 `lark-drive`。
- 钉钉：优先读取本机 dws 安装流程提供的文档/云盘 Skill；具体名称与子命令以已安装官方 Skill 和 `dws --help` 为准。
- CLI 或官方 Skill 缺失时停止该平台的发布，给出官方来源和缺失项。不得自动下载、安装或复制外部 Skill。
- 用户要求安装或更新官方 Skill 时，先执行其强制 SkillSpector 安全检查流程。

### 3. 认证与权限预检

1. 使用官方 Skill 规定的只读认证状态命令确认登录身份。
2. 只申请创建/更新文档与访问目标文件夹所需的最小权限。
3. 不在输出、日志或命令参数中暴露 Token、App Secret、Cookie 或刷新凭证。
4. 若需要浏览器授权，把官方授权链接交给用户完成；不要代替用户选择账号或扩大权限。

### 4. 形成发布计划

在任何外部写入前列出：平台、源文件、目标文件夹、云文档标题、创建/更新动作以及本地资源风险。

用户已经明确给出平台、目录、标题并说“发布/推送/同步”时，可按该计划直接执行。以下情况必须先询问一次：

- 平台未指定。
- 模块名称无法唯一推断，导致默认文件夹不确定。
- 找到多个同名文件夹或多个同名文档。
- 更新会覆盖无法确认归属的已有文档。
- 用户只要求预览、检查或准备，没有授权实际发布。

### 5. 创建或更新

1. 先解析目标文件夹的唯一标识；不存在时按计划创建。
2. 按“源文档逐篇、平台逐个”执行，记录每一步结果。
3. 优先使用官方 Skill 支持的 Markdown 创建/更新能力，保留标题层级、表格、代码块和 Mermaid 源码。
4. 若平台不原生渲染 Mermaid，保留 Mermaid 代码块，并在结果中提示；不要擅自生成与源文档不一致的图片。
5. 更新后重新读取云端标题和正文摘要；平台支持时比对内容或版本标识。
6. `都发布`时两个平台互不回滚：一个失败不删除另一个已成功文档，而是继续收集结果并报告部分成功。

### 6. 错误处理

按错误类型处理，不做无差别重试：

| 错误 | 处理 |
|---|---|
| 未登录/授权过期 | 停止，给出官方重新授权步骤 |
| 权限不足 | 停止，指出缺少的最小权限或目标目录权限 |
| 参数或命令不匹配 | 重新读取官方 Skill 与 `--help`，修正一次 |
| 限流/临时网络错误 | 按官方建议退避，最多重试两次 |
| 目标不唯一 | 停止并让用户选择 |
| 源文件变化 | 停止该文件，重新计算计划与哈希 |
| 平台不支持的格式 | 保留可表达内容并列出降级项，不静默丢失 |

禁止通过切换身份、扩大授权、关闭安全校验或调用未审查脚本来绕过失败。

### 7. 交付结果

返回紧凑结果表：

| 平台 | 源文件 | 动作 | 目标文件夹 | 云文档标题 | 状态 | 链接/错误 |
|---|---|---|---|---|---|---|

同时说明：成功数、失败数、格式降级、是否仍需用户授权，以及下次重复执行会创建还是更新。不要只说“已推送成功”而不提供可核验链接或平台返回标识。

## 安全边界

- 不删除云端文档、移动无关文件、修改共享范围或通知他人，除非用户明确要求。
- 不读取目标发布所不需要的其他云文档内容。
- 不把公司内部文档上传到用户未指定的平台或个人空间。
- 发布前后都不得修改本地源文档；内容调整应回到文档生成流程完成。
